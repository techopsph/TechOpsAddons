Website Slides - Custom Video Embed

Odoo 18.0 | GitHub | Contact Maintainer

Module Purpose: Adds support for a custom video embed type in eLearning slides using the embed_code_custom field.

  • Installation
  • Usage
  • Maintainers

Installation

Install this module like any standard Odoo addon. It depends on the website_slides module.

Usage

  1. Navigate to eLearning → Courses → Slides.
  2. Create or edit a slide with category = Video.
  3. Set Video Source to Custom.
  4. Paste your embed code into the Custom Embed Code field.

The content will render on the website using your iframe/embed code.
